# 六级搭子 · CET-6 Buddy

一个不用下载、不用注册的六级背词工具。打开网页就能用，可以添加到手机主屏幕，断网也能背。

## 特点

- **4137 个六级词汇**，从《大学英语六级词汇完整版带音标》PDF 解析，去掉了 the/a/is 这类基础词
- **每天 50 词，分 5 批**：每批 10 个词先学，学完立刻测，测完才解锁下一批
- **两种题型交替**：看单词选释义、看释义拼单词（带首字母提示和音标）
- **错词自动归集**：答错次数 +1，复习时优先抽错得最多的
- **1063 条例句**，来自公开词典语料，没有的不显示——不编造
- **零依赖**：单个 HTML 文件，词库内嵌，不请求任何接口
- **离线可用**：Service Worker 缓存，断网照常打开
- **进度本地存**：存在浏览器 localStorage，不上传任何服务器

## 怎么用

### 手机上（推荐）

- **iPhone**：Safari 打开 → 底部「分享」→「添加到主屏幕」
- **安卓**：Chrome 打开 → 右上角「⋮」→「添加到主屏幕」

加完后主屏幕会有一个图标，点开是全屏的，跟原生 App 一样。

### 电脑上

直接用浏览器打开 `index.html` 即可。

## 词库说明

| 项 | 值 |
|---|---|
| 词条总数 | 4137 |
| 有例句 | 1063（26%） |
| 音标 | 已规范化为 IPA（ˈ ˌ） |

**学习顺序**按备考优先级分四档：

1. 词频 5000–10000：不常用但真实存在 → 最该背
2. 词频表未收录：六级生僻词
3. 词频 3000–5000
4. 词频 2000–3000：基础词，排最后

同档内按词频从高到低，避免一上来全是生僻词。

## 自己导入词表

「我的」→「导入自己的词表」，支持三种格式：

```csv
abandon, v. 放弃；抛弃
tentative, adj. 试探性的
```

```json
[{"w":"abandon","d":"v. 放弃","p":"əˈbændən","e":"例句"}]
```

导入后合并进当前词库，同名条目会覆盖。数据存在本机浏览器。

## 文件结构

```
.
├── index.html      主程序（词库已内嵌，单文件可运行）
├── sw.js           Service Worker（离线缓存 + 自动更新）
├── manifest.json   PWA 配置（添加到主屏幕）
└── README.md
```

`index.html` 里 `window.__VOCAB__` 就是词库数组，字段含义：

| 字段 | 含义 |
|---|---|
| `w` | 单词 |
| `p` | 音标 |
| `d` | 中文释义 |
| `e` | 例句（可能为空） |
| `c` | 常见搭配（可能为空） |
| `f` | 排序序号（越小越先学） |

## 部署

纯静态页面，任何静态托管都能用：

- **GitHub Pages**：Settings → Pages → Source 选 `main` 分支 `/root`
- Vercel / Netlify：直接拖文件进去
- 自己电脑：双击 `index.html`

## 数据与隐私

- 不收集任何信息
- 不发送任何网络请求（除了加载页面本身）
- 学习进度只存在你浏览器的 localStorage 里
- 换设备不会自动同步，用「我的 → 导出学习记录」手动迁移
